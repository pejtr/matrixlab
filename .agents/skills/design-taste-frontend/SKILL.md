# Anti-Slop Design Taste Guide

## Core Principles

1. **Eliminate Generic AI Aesthetics**:
   - NO generic centered black-and-white hero layouts with plain purple/pink gradients and standard rounded badges.
   - NO uniform grid of identical cards with subtle gray borders.
   - NO generic placeholder texts or flat static previews.

2. **Typographic Distinction & Character**:
   - Pair an expressive, editorial display font (e.g. `Syne`, `Outfit`, `Cabinet Grotesk`) with crisp monospaced tech accents (`JetBrains Mono`, `Space Mono`) and clean body sans (`Plus Jakarta Sans`).
   - Use dramatic typography scale (oversized display text, high contrast headers, tight letter spacing for display titles).

3. **Asymmetric & Dynamic Layouts**:
   - Use overlapping layers, offset cards, glassmorphic floating panels, and dynamic visual weight.
   - Break strict repetitive grids with featured highlight cards, interactive canvas previews, and live prompt morphers.

4. **Rich Motion & Micro-Interactions**:
   - Add spring transitions, magnetic button effects, cursor-responsive tilt cards, ambient floating glow particles, and live status pulses.

5. **Color & Lighting**:
   - Deep obsidian dark canvas with rich accent glows (emerald cyan `#06b6d4`, electric violet `#8b5cf6`, vibrant rose `#f43f5e`, bright amber `#f59e0b`).
   - Subtle noise overlay texture or ambient glass blur for high tactile quality.
